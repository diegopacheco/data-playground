Postgres as a lakehouse with pg_lake

Heap tables and Iceberg tables in one Postgres, Parquet on MinIO, queries executed by DuckDB through pgduck_server.

Run the pipeline

CSV rows go into a heap landing table, Postgres exports them as Parquet to s3://lake/raw/orders/, a pg_lake foreign table reads the Parquet back and inserts it into the Iceberg table orders, partitioned by month(order_date).
