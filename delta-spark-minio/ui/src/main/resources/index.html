VACUUM runs with RETAIN 0 HOURS, which Delta refuses by default. The job sets spark.databricks.delta.retentionDurationCheck.enabled=false only for this POC so the effect is visible right away. With 0 hours every file not referenced by the latest version is deleted, so time travel to version 0 and the change feed for older versions stop working.
